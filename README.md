# Stream Sidekick

Stream Sidekick is an Electron desktop app for running commercial breaks, bumper music and a live scoreboard during a stream. It drives OBS Studio over its WebSocket API, and an Elgato Stream Deck plugin lets you run breaks from deck keys.

The source is not in this repository; it only hosts releases.

## Download

Get the latest build from the [Releases page](https://github.com/ogl33t/stream-sidekick-v2-releases/releases/latest).

- **Windows:** `Stream-Sidekick-Setup-X.Y.Z.exe`
- **macOS:** not published at the moment.

## Stream Deck plugin

The plugin needs Stream Deck 7.1 or later. Install it from Settings → "Install Stream Deck plugin", or double-click the attached `stream-sidekick-X.Y.Z.streamDeckPlugin`. When the app is updated it offers to update the plugin too.

## Updates

Windows checks for updates on launch and installs them on restart.
